Консольный калькулятор. Калькулятор поддерживает следующие действия: сложение, вычитание, умножение, деление и возведение в степень.

Сборка проекта
```
cmake -B build
cmake --build build
cmake --build build --target install
```


Пример использования
```
./calc 2 \* 3
```

```
./calc 2 ^ 3
```

```
./calc 2 + 3
```
